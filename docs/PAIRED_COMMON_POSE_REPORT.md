# H2: ranking one exact retained union with and without CHI

Execution boundary: this adapter enforces its local union workflow gate. Enforcement of the four-workflow conjunction belongs exclusively to the calling pinned global guard. The Python API is not an authorization mechanism; a supplied dictionary does not independently prove freshness. The guard computes and passes the main report immediately, and the CLI exposes no metric-file input or actual-evaluation command.

This extension compares the original Vina-Carb 1.0/Vina 1.1.2 core at CHI coefficients 0 and 1 on the identical retained pose pool. It inherits the frozen common-pool scoring plan and main V2 atomic evaluation plan. The original modern-Vina and Vina-Carb searches remain separate source algorithms; this extension does not rescore with the modern Vina 1.2.7 engine.

There are 108 eligible pools: six cases, strict and repair receptor profiles, three site arms and three seeds. Every returned source model belongs to its exact pool, including coordinate duplicates. No pose is deduplicated, repaired or removed. Both coefficients must rank the complete union with the frozen score/source-algorithm/candidate/model tie order. Any source failure, fixed-pose failure or case-wide torsion-normalization conflict prevents both rankings; the eligible outcomes remain zero recovery. Unsupported preparation/preflight mechanisms and failed execution/scoring mechanisms remain explicit. Every available source pose still needs a terminal fixed-score record even when another source has already failed.

The validation-only `probe_workflow(root, plan_path, freeze_path, require_freeze=True)` reads frozen source execution and score evidence. It calls the unchanged indexer with a disposable temporary output, reads the actual checked score manifest with orphan recovery disabled, and reconstructs existing exported poses in temporary directories. It never writes the live source index, score manifest or records. It returns normalized workflow counts and pending/ready status, always with `metrics_eligible=false`, `atomic_accuracy_computed=false` and `experimental_reference_access=false`. It does not invoke the main metric reader, fits, contacts, geometry diagnostics or statistics.

The separate global guard requires all four workflows to be ready before any actual accuracy. H2 itself additionally requires all 216 source-method slots and every retained pose's fixed-score record to be terminal, covering all 108 pools and 216 coefficient outcomes. The CLI exposes only proposal generation and this validation-only probe:

```sh
python scripts/regenerate_paired_common_pose_report.py --root . --example
python scripts/regenerate_paired_common_pose_report.py --root . --plan FINAL_PLAN --freeze ROOT_FREEZE
```

After the global release, `generate_report(root, plan, freeze, main_report=main_result)` accepts the pinned guard's freshly generated in-memory main result. There is no cached metric-file input. If the argument is absent, the unchanged main generator runs freshly after the same local H2 gates. The guard supplies its already generated main result to avoid repeating fits. The extension validates exact condition/seed/source-algorithm/model-rank identities; raw source-file, MODEL-block and canonical execution-record hashes; source/input identities; candidate ranks; source native scores; and the main reader's checksum inventory. Missing, extra or duplicate metric rows fail validation.

Per-pose global/local RMSD, qualified-copy correspondence, graph/stereo diagnostics, clashes and contacts are copied unchanged. No ligand fit, per-pose metric calculation or geometry filter is added. Only copied ranking metadata changes. The unchanged `accuracy_summary` supplies Top1, Top5 and best-retained recovery at 1/2/3 Å. Both coefficients must have identical best-retained RMSD and threshold decisions in every completed pool. Their per-pose identity sets and failure denominators are also identical. Original source orders are retained as metadata; comparing those orders to a union ranker changes pool membership and cannot isolate CHI.

Five complete-ligand references and the single 11-atom modeled-core reference stay separate, as do receptor profiles and site arms. The unchanged statistics helper averages seeds within cases and cases within source families, then performs paired family-cluster resampling with 10,000 requested resamples, seed 20261103 and confidence 0.95. Failures remain eligible at zero; completed and near-native conditional summaries include their denominators. One family has no estimable between-family interval. These are descriptive results for a purposive structural sample, with no population or model-training-unseen claim. Absence of an accurate pose from the retained union cannot distinguish internal search failure from retention/pruning.

The implementation was completed after 580 native fixed-score records existed. No atomic accuracy was consulted. Metric choices are inherited from the prior frozen plans; this separate report implementation and its global release need their own source pins and pre-accuracy freeze. Tests use synthetic metric tables and public source-only clones with empty native tools, absent processed inputs and the finite publication-snapshot waiver. No live readiness probe or actual accuracy is executed while preparing this proposal.
